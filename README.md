# Workshops

This repository contains workshop materials, example UI prototypes, and exercises intended for hands-on learning and demonstration.

Goals
-	Host interactive workshops and demos that teach web UI/UX concepts.
-	Provide simple, self-contained examples participants can open in a browser.

Repository structure
- UI/: Front-end examples and workshop HTML files.
  - UX/: Example pages used in workshops (e.g. master-editor-workshop.html).

Quick start
1. Clone the repo:

	git clone <repo-url>

2. Open any workshop HTML directly in your browser. For example, open:

	UI/UX/master-editor-workshop.html

Notes for presenters
- Keep examples minimal and focused on the concept you want to teach.
- Test pages in Chrome and Firefox before the session.

Contributing
- Pull requests are welcome — keep changes focused and include a short description of the workshop or exercise you add.
